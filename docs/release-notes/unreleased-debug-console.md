# 调试台（面板）—— 未发布的功能记录

> 状态：已在仓库内实现并逐阶段验收，**未发布新版本**（`package.json` 仍为 0.1.7）。本文件记录这次「调试台」系列改动的内容与验证口径，供发布时整理 changelog 使用。

## 它是什么

DSH 主窗口会话页签里的一个工作面板（`conversation.view`，id `stm32-debug`，order 40），用于「人 + AI 一起看同一件事」：AI 调 `stm32_*` 工具做了什么、结果如何、硬件现在什么状态，都在同一处按时间线展开。

不是仪表盘，也不是编辑器：不做代码编辑、不改 `.ioc`（除非点了明确的「恢复 / 批量设优先级」这类写操作），所有展示都从既有工具与工程文件里读。

## 十个标签

| 标签 | 看什么 | 能做什么 |

| 概览 | 工程、型号、SYSCLK、容量、调试会话、工具链、构建/烧录、证据占用、告警一句 | 跳到失败筛选、实时通道，导出操作记录 Markdown |

| 实时通道 | 串口 / RTT / 监视三路输出 | 暂停、清空、关键字过滤、RTT 级别过滤、发送串口行、常驻采集、导出文本 |

## 数据面

- 45 条 `/dsh-stm32/api/*` 路由；事件流用 SSE（`/events?since=<seq>&session=<id>`），先补发存量再增量。
- 环形缓冲 5000 条、单条 payload 8 KB；**每 30 秒**把本会话未落盘的事件写进 `~/.dsh-stm32/evidence/<日期>/<会话>/events-<时分秒>.jsonl`。
- 保留策略：7 天或 20 个会话，超出由 `pruneEvidence` 清理；面板可手动触发并显示占用。
- 调试会话、串口、RTT、监视、构建、烧录都从既有引擎读，面板不另起一套状态。
