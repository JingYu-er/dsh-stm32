# v0.1.6 —— 安装包只下载，不安装

> **归档说明（2026-11-12）**：本文件描述的内容已并入 v0.1.5 发布；仓库没有发布 0.1.6 版本。

> 继 v0.1.5（2026-11-09）之后的下一个版本。0.1.5 补上了 Windows 串口 P1 与寄存器 21 族；0.1.6 只做一件事：**把「拿到安装包」和「安装」分开**。
>
> 一句话：**J-Link 可以按官方直链下载并校验 SHA256；CubeMX / CubeProgrammer 只打开官方页或校验本地安装包；插件绝不执行安装器、不写注册表、不改 PATH、不请求管理员。**

## 亮点

- **只下载，不安装**：`stm32_download` 的四种模式是 `plan`（默认，只出计划）、`direct`（J-Link 真下载）、`manual`（打开 ST 官方页）、`file`（只校验本地安装包）。`dryRun` 默认 `true`；`direct` / `manual` 必须再给 `confirm: true`。
- **J-Link 8.18.0 固定直链 + 固定哈希**：`https://files.nordicsemi.com/artifactory/swtools/external/jlink/JLink_Windows_V818_x86_64.exe`，SHA256 `63110b6fc55e494d197d6efa156d7f61c0dd0c1f776424995a05407e2d7f566f`，约 59 MB；边写边算哈希，校验通过才原子改名。
- **ST 不猜直链**：CubeMX / CubeProgrammer 需要 myST 登录与许可，直链会过期；默认只返回官方页面与安装提示，不伪造下载地址。
- **失败不留垃圾**：网络中断、超时（默认 10 分钟）、超过 300 MB 或哈希不符时删除 `.part-<pid>-<ts>`；已有同哈希文件直接复用（`cached: true`）。
- **下载根目录可配**：`DSH_STM32_DOWNLOADS` > `%LOCALAPPDATA%\dsh-stm32\downloads` > `%USERPROFILE%\AppData\Local\...` > 临时目录；也可用 `outDir` 单次覆盖。

## 不做什么（边界）

- 不执行安装器：没有 `spawn` 安装包，`manual` 只打开浏览器。
- 不写注册表、不改 PATH、不请求管理员。J-Link 的 USB 驱动由安装器自己处理（`-InstAllUsers=1` + UAC）；现代探针默认 WinUSB，只有停产老探针需要 legacy 驱动。
- 不提供 ST 的直链，也不绕过 myST 登录/许可。
- 不保证驱动一定能装上：Problem Code 28/52 可能要靠设备管理器或换探针解决。

## 验证

| 命令 | 结果 |
| --- | --- |
| `npm run build` | exit 0 |
| `node test/download-units.test.mjs` | 5 pass / 0 fail |
| `node test/run-units.mjs` | **pass=937 fail=0**（59 个套件） |
| `npm run test:pack` | 全部通过（含解包产物建寄存器工程） |
| `npm run test:size` | 1809.8 KB（上限 3906.3 KB）/ 解包 15125.8 KB / 271 个文件 |

- J-Link 直链只做 `HEAD`：HTTP 200、`content-length: 59,012,800`；**没有真的下载 59 MB**，也没有运行安装器（按设计永远不运行）。
- 下载/缓存/哈希不符清理用本机 HTTP 服务覆盖；ST 页面只验证 URL 与计划输出，没有打开浏览器。
- 真机安装、驱动加载、CubeMX / CubeProgrammer 的 myST 下载仍未验。

## 安装 / 升级

```powershell
dsh plugin --profile desktop add dsh-stm32@0.1.6
# 或从 GitHub 主线：dsh plugin --profile desktop add github:JingYu-er/dsh-stm32#main
```

装完确认：`dsh plugin --profile desktop why dsh-stm32` 应显示 `0.1.6`；重启 dsh 后才加载新代码。

## 已知限制

- 只覆盖 Windows 的下载路径与官方页面；Linux / macOS 没有专门的下载器。
- J-Link 的版本与哈希写死在 `src/engine/download.ts` 的 `JLINK_DOWNLOAD`；SEGGER 发新版后要同时改 URL 与 SHA256。
- 没有下载进度条；长下载只能等工具返回。
